📖 Sobre o projeto

Onde a Alma Dança é uma página web dedicada ao universo da dança, especialmente ao ballet e às diferentes formas de expressão artística.

O projeto apresenta conteúdos sobre a história do ballet, estilos de dança e a importância da dança como forma de expressão dos sentimentos.

✨ Funcionalidades

- 🩰 Apresentação sobre o universo da dança.
- 📚 Conteúdo sobre a história do ballet.
- 💃 Informações sobre diferentes estilos de dança.
- 🎨 Layout personalizado com cores e tipografia.
- 📱 Estrutura adaptável a diferentes tamanhos de tela.
- 🖼️ Exibição de imagem ilustrativa.

🛠️ Tecnologias utilizadas

Tecnologia| Utilização
HTML5| Estruturação do conteúdo
CSS3| Estilização e layout

🎨 Identidade visual

- Fundo escuro.
- Detalhes em roxo.
- Conteúdo centralizado em um cartão branco.
- Tipografia Georgia.
- Bordas arredondadas.

🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Certifique-se de que a imagem "bailarina.jpg" esteja na mesma pasta do arquivo HTML.
4. Abra o arquivo "index.html" no navegador.

📥 Clonar o repositório

git clone URL_DO_REPOSITORIO

🎯 Objetivo

Demonstrar conhecimentos básicos de desenvolvimento web utilizando HTML5 e CSS3, criando uma página temática com conteúdo organizado e identidade visual própria.
